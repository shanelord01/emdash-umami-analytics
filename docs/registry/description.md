Shows your Umami numbers inside the EmDash admin: site traffic on the dashboard, and page views next to the entries that earned them. For Umami Cloud and a self-hosted Umami from 3.4.0.

- **Dashboard card.** Visits, page views and engagement for the last seven days against the week before, and the five most viewed pages with their entries.
- **Analytics page.** A daily chart over 7, 30 or 90 days, bounce rate and visit time, top entries, referrers, countries, page views by the event data your site attaches (by category, to start with), and a setup check that names the fix for each problem it finds.
- **Views per entry.** Every published entry with its page views over 7 and 30 days, sortable, for one collection or all of them, with translations combined if you like.
- **Editor panel.** Each entry's 7 and 30 day page views beside the editor, and how far readers get when your site sends a read event.
- **MCP tools.** Four read-only tools that answer from the stored numbers.

The plugin only reads. It never changes anything in Umami or in your content. Demo data lets you try it without an Umami website.

It is tested with a self-hosted Umami 3.4.0. The Umami Cloud connection follows Umami's published API and has not been run against a Cloud account yet.
